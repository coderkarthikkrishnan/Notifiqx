# Slide 7: Process Flow

**Title:** How It Works (Faculty Perspective)
**Visual:** (Placeholder for Flow Diagram)

1.  **Draft:** Faculty types a rough notice (e.g., "exam tmrw cancelled").
2.  **AI Polish:** Clicks "Polish with AI" -> Gemini converts it to specific formal text.
3.  **Post:** Selects category (Urgent) and posts.
4.  **Notify:** Database triggers real-time update.
5.  **View:** Students see the verified notice instantly on their feed.
